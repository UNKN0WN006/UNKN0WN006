# Setup

Use this pack in the special profile repository `UNKN0WN006/UNKN0WN006`.

1. Copy the entire ZIP contents into the repository root.
2. Commit and push.
3. Go to **Settings → Actions → General → Workflow permissions**.
4. Enable **Read and write permissions**.
5. Run **Update 365-Day Orbit** once.
6. Run **Update Profile Telemetry** once.

Important:
- Forecast Engine: `assets/forecast-engine.svg`
- Current research board: `assets/research-board.svg`
- The README only embeds those SVG files. Do not paste the SVG source into README.
- The old snake is intentionally removed.
- `orbit.yml` generates a custom 365-day contribution graph from your GitHub contribution calendar.
- `profile-stats.yml` generates self-hosted activity, streak and language cards.
- Project buttons currently point to your repositories tab. Replace them with direct repo links once you choose the exact public repositories to showcase.
